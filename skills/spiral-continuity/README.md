## Install

```bash
# Local / folder install (OpenClaw)
openclaw skills install ./spiral-continuity

# Or copy into your workspace skills directory
cp -r spiral-continuity ~/.openclaw/workspace/skills/
```

ClawHub publish (when ready):

```bash
clawhub login
clawhub skill publish ./spiral-continuity \
  --slug spiral-continuity \
  --name "Spiral Continuity" \
  --changelog "Initial continuity method skill with bundled methodology brief"
```
