## Purpose

This repository is the dedicated **agent hub** for Spiral work that must talk to other networks and agent runtimes (OpenClaw, Discord, Agensi, ClawHub, and future channels).

It holds:

| Area | Role |
|------|------|
| **Legal** | Public Privacy Policy & Terms of Service (Discord / app compliance) |
| **Agents** | Orientation and home notes for Grok-backed bots |
| **Skills** | Pointers and install notes for Spiral skills (e.g. spiral-continuity) |
| **Compatibility** | Odds and ends for interop with other agent platforms |
| **Docs** | Short operational notes for deployment |

It does **not** replace `spiral-theory-core`, `The-Spiral-Codex`, or the method repos. Those remain the living theory and tooling lattice. This hub is the **deployment / interop / legal** surface.
