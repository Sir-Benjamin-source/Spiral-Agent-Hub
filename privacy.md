## 2. What data we process

Depending on how an agent is configured and which channels it is invited to, it may process:

- **Discord (or similar chat) data:** message content in channels or DMs where the bot is present, usernames, display names, user IDs, channel and server IDs, timestamps, and roles visible to the bot
- **Operational logs:** limited technical logs needed to run the gateway (errors, connection status) on the operator’s machine or host
- **Model provider traffic:** when a cloud model (e.g. xAI Grok) is used, prompt context may include message text the agent is asked to handle; that traffic is subject to the model provider’s own terms and privacy policy

We do **not** intentionally collect payment card numbers, government IDs, or similar sensitive identity documents through these agents.

---

## 3. How we use data

Data is used only to:

- Provide the agent’s functions (reply, continuity seals, skill behavior, moderation aids as configured)
- Maintain reliability and security of the local or hosted gateway
- Comply with platform rules (e.g. Discord) and applicable law

We do **not** sell personal data. We do not use Discord message content for advertising.

---

## 4. Model providers

If the agent is configured to use a third-party model API (for example xAI), content necessary for the request is sent to that provider under their terms. The operator’s configuration determines which provider is used. Prefer providers and tiers whose API terms match your comfort level regarding logging and training.

---

## 5. Retention

- Chat content is not stored by us as a long-term archive unless a specific continuity or logging feature is explicitly enabled by the operator.
- Local OpenClaw / gateway workspaces on the operator’s machine may retain session files under the operator’s control.
- You may remove the bot from a server or block it in DMs at any time; that stops further processing in that context.

---

## 6. Your choices

- Do not invite the bot to channels where sensitive personal data is routinely discussed.
- Server admins can kick or ban the bot; users can block DMs.
- For questions about this policy, use the Agensi creator contact path above.

---

## 7. Children

These agents are not directed at children under 13. Do not use them to collect data from children.
